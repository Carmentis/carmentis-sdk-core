# Using the Carmentis KMS from the SDK

The Carmentis KMS manages **wallets**. A wallet is:

- one **private signature key**, generated by a KMS plugin;
- one **actor seed**, generated by the server (encryption keys will be derived from it);
- one **wallet API key** (`wlt_…`), used to operate the wallet.

None of them leaves the KMS (the API key is returned once, at creation or regeneration). Each wallet
is administered by an **admin key**: your own Carmentis signature key, which the KMS only knows by its
public part.

The SDK exposes (all exported from `@cmts-dev/carmentis-sdk-core`):

| Class | Credential | Role |
|---|---|---|
| `CarmentisKmsClient` | none | HTTP transport and public endpoints (plugins, wallet public keys, challenges). |
| `KmsWalletAdmin` | admin key (signed requests) | Create, list, hand over, regenerate the API key of, and delete your wallets. |
| `KmsWalletClient` | wallet API key | Sign (raw / JSON), certificates, CSR. |
| `KmsPrivateSignatureKey` | wallet API key | The wallet key as a `PrivateSignatureKey`, whose `sign()` is delegated to the KMS. |
| `KmsManagementClient` | global API key (`jwks_…`) or administrator JWT | Manage any wallet. These credentials never sign. |

```ts
import {CarmentisKmsClient} from "@cmts-dev/carmentis-sdk-core";

const kms = new CarmentisKmsClient({baseUrl: "https://kms.example.com"});
```

## 1. Discover plugins

Each plugin lists its `capabilities`. The `key/create` capability carries the JSON Schema of the
parameters expected when creating a wallet.

```ts
const plugins = await kms.listPlugins();
const local = plugins.find(p => p.id === "local")!;
const createSchema = local.capabilities.find(c => c.method === "key/create")?.params;
```

Known methods: `key/create`, `key/public`, `sign/raw`, `sign/json`, `cert/get`, `cert/create-self-signed`, `cert/csr`.

## 2. Administer wallets (signed requests)

```ts
import {KmsWalletAdmin, Secp256k1PrivateSignatureKey} from "@cmts-dev/carmentis-sdk-core";

const adminKey = Secp256k1PrivateSignatureKey.gen(); // or load your persisted key
const admin = new KmsWalletAdmin(kms, adminKey);

const created = await admin.createWallet({
    pluginId: "local",
    params: {algorithm: "ES256"}, // validated against the plugin's key/create schema
    label: "Invoices",
});
const walletId = created.id;
const apiKey = created.apiKey; // returned only once: store it securely

const mine = await admin.listMyWallets();
const {apiKey: newApiKey} = await admin.regenerateApiKey(walletId); // the previous one stops working
await admin.setAdminKey(walletId, "sig:secp256k1:pk:…");            // this admin key loses all rights
```

Every call is a signed request. The SDK:

1. gets a single-use nonce: `POST /api/wallets/challenge`;
2. builds `payload = {challenge, method, path, body}`, where `method` and `path` are those of the
   request about to be sent (path without query string) and `body` is the operation input;
3. signs the RFC 8785 canonical JSON of `payload` with the admin key, and sends
   `{publicKey, signature, payload}`.

The signature covers the method, the path and the body, and the nonce can't be replayed.
`admin.signRequest(method, path, body)` builds such a body if you need to send it yourself.

> `createWallet` is rejected with `403` unless the KMS administrators enabled public creation.
> They can still create a wallet for you with `KmsManagementClient.createWallet({adminPublicKey, …})`.

## 3. Use a wallet (wallet API key)

```ts
const wallet = kms.wallet(walletId, apiKey);

const key = await wallet.getSignatureKey();       // KmsPrivateSignatureKey
const data = new TextEncoder().encode("hello world");
const signature = await key.sign(data);           // POST /api/wallets/{id}/sign/raw

const publicKey = await key.getPublicKey();        // KmsPublicSignatureKey, verified locally
console.log(await publicKey.verify(data, signature)); // true
```

`KmsPrivateSignatureKey.fromWallet(wallet, publicJwk?)` does the same; pass the public JWK to skip the
public-key request.

Other wallet operations:

```ts
const info = await wallet.getWallet();
const caps = await wallet.getCapabilities();   // methods this wallet supports; others answer 501
const raw = await wallet.signRaw(data);        // ECDSA: r||s (IEEE P1363)

const result = await wallet.signJson({
    payload: {documentId: "doc-42", amount: {value: 1250.5, currency: "EUR"}},
    context: {purpose: "invoice-approval"},   // signedAt (ms) defaults to now
    signatureType: "json-canonical+utf8",      // or "jws"
});
```

## 4. Public keys (no authentication)

```ts
const jwk = await kms.getPublicJwk(walletId);
const carmentisPk = await kms.getPublicKey(walletId); // Carmentis string encoding
```

## 5. X.509 certificates

```ts
const chain = await wallet.createCertificates("self-signed", {
    subject: "CN=My key, O=Acme", san: ["example.org"], validityDays: 365,
});
// Or ask the key provider: await wallet.createCertificates("fetch");

// Or produce a CSR, get it signed by your CA, then import the chain (PEM, leaf first).
const csr = await wallet.createCsr({subject: "CN=My key, O=Acme"});
await wallet.importCertificates([/* leaf PEM, intermediates… */]);

const attached = await wallet.getCertificates();
```

## 6. Management (administrators / global API keys)

```ts
import {KmsManagementClient} from "@cmts-dev/carmentis-sdk-core";

const manage = new KmsManagementClient(kms, {apiKey: "jwks_…"}); // or {bearerToken: adminJwt}
const created = await manage.createWallet({adminPublicKey: "sig:secp256k1:pk:…", label: "Invoices"});
// Hand created.apiKey over to the wallet holder.
const all = await manage.listWallets();
const theirs = await manage.listWallets("sig:secp256k1:pk:…");
```

## 7. Error handling

Non-2xx answers throw a `KmsError` carrying the HTTP status and the parsed body.

```ts
import {KmsError} from "@cmts-dev/carmentis-sdk-core";

try {
    await wallet.createCsr({subject: "CN=x"});
} catch (e) {
    if (e instanceof KmsError && e.isUnsupported()) {
        console.warn("The wallet's plugin does not implement this method (HTTP 501)");
    } else if (e instanceof KmsError && e.isNotFound()) {
        // Unknown wallet, API key of another wallet, or signer not admin of this wallet.
    } else {
        throw e;
    }
}
```

## 8. Cleanup

```ts
await admin.deleteWallet(walletId); // destroys the private key, the actor seed and the API key
```
